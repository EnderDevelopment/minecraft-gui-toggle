# GuiToggle

GuiToggle is a Minecraft plugin that provides functionality to open and close a GUI (Graphical User Interface) using a button item and a keybind. The plugin ensures that the GUI can only be opened when it is closed and vice versa, preventing any conflicts or issues.

## Install

1. Download the plugin JAR file from the releases section of the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart or reload your Minecraft server to load the plugin.

## Use

1. Join the Minecraft server where the plugin is installed.
2. You will receive a stone button item in your inventory.
3. Right-click with the stone button to open the GUI.
4. Inside the GUI, click the stone button to close it.
5. The GUI can only be opened when it is closed, and vice versa.
